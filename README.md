## Traffic Crash Analytics & Safety Intelligence Platform
**Project Overview**

The Traffic Crash Analytics & Safety Intelligence Platform is a data analytics project designed to analyze traffic crash records and generate actionable road-safety insights. The project uses:

•	**Python** (Pandas) for data processing

•	**MySQL** for data storage and SQL analytics

•	**SQL** Window Functions & Aggregations for advanced analysis

•	**Streamlit** for interactive dashboard visualization

The objective is to identify accident hotspots, understand crash patterns, analyze injury trends, and provide insights that can help traffic authorities improve road safety.


**Project Workflow**

Traffic Crash Dataset
        │
Data Loading using Pandas
        │
Data Cleaning & Transformation
        │
Store Data in MySQL Database
        │
Run Advanced SQL Queries
        │
Generate Safety Insights
        │
Display Results in Streamlit Dashboard

**Dataset Description**

The project uses a Traffic Crash dataset containing information such as:

Crash Record ID
Crash Date
Year
Street Information
Weather Conditions
Crash Type
Traffic Control Devices
Lighting Conditions
Injuries
Latitude & Longitude
Primary and Secondary Causes

These fields help analyze accident trends and identify risk factors.
